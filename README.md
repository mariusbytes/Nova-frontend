# Landing Page Project

My first front-end project built using only HTML and CSS.  
This project focuses on learning layout, Flexbox, and basic UI structure.

## Features

- Hero section
- Features section
- Pricing cards
- Contact form
- Multi-column footer (currently placeholder links)

## Technologies

- HTML5
- CSS3 (Flexbox)
